# 두 실행 트랙 비교 평가 — Claude 트랙 vs Gemini 트랙

작성 2026-10-22 · 평가 대상: 루트 트랙(Claude 실행, 이하 Claude) / `gemini-exp/`(Gemini 실행, 이하 Gemini)
집계 방법: 양쪽 검증 CSV와 종합 보고서(`docs/00`)를 같은 문항·조건 정의로 재집계

## 1. 비교 가능성

두 트랙은 우연히 비교 가능한 조건을 갖추고 있다.

- **같은 표본 풀**: 논문 공개 1k 하위 표본에서 seed 20261019로 추출한 150명 (SHA-256 `ef98881b…` 동일). Claude는 앞 100명, Gemini는 150명 전원 사용.
- **같은 문항**: 발표자료 원문 확인 2문항 + 재구성 10문항으로 이루어진 파일럿 12문항이 동일하다. 조건 설계(A 재현 / B 무페르소나 / C 속성 주입 4종)도 같은 하네스에서 나왔다.
- **다른 응답 모델**: Claude = 현재 세대 Opus, Gemini = google/gemini-2.5-flash. 응답자가 다르므로 수치 차이는 곧 모델 차이로 읽을 수 있다.

## 3. 판정

### 판정 1 — 논문의 핵심 주장(소수자 소거)은 두 트랙이 독립적으로 확인한다

서로 다른 회사의 모델, 다른 표본 크기, 다른 온도·문구 조건에서도 페르소나 조건의 소수자 문항은 전부 0~1%다. 어느 한쪽의 실행 실수나 특정 모델의 특이성으로 설명할 수 없으며, 현상의 교차 검증으로 읽을 수 있다.

### 판정 2 — 주입 실험의 결론도 일치한다: 라벨은 남고, 정신적 고통은 따라오지 않는다

- Gemini 조건 C (속성당 n=150): 주입한 속성의 유지율이 4종 전부 100%. 장애 주입 시 자가보고 장애는 42% (63/150)까지 따라왔다. 그러나 자살 생각은 주입 종류와 무관하게 0~1.3%, 자살 시도와 배우자 폭행은 전 조건 0건.
- Claude 모듈 3/3b (속성당 n=20): 라벨 유지 100%, 신체 기능 차원은 주입 문구가 강하면 포화까지 상승, 자살 생각은 6개 조건 전부 0/20.
- 규모는 Gemini가 크고(속성당 150 vs 20), 깊이는 Claude가 깊다(주입 강도 3단계 용량-반응, 1차 결론의 자기수정 포함). 방향은 완전히 같다. 침묵의 경계가 신체와 정신 사이에 있다는 해석을 양쪽이 지지한다.

### 판정 3 — 갈리는 곳은 대조 문항의 과대추정 크기다

고혈압: Opus 50.0% (실제 24.1%의 약 2배) vs Flash 25.3% (실제값에 근접). 학업 중단: Opus 31.0% vs Flash 16.0% (실제 9.2%). 흡연은 양쪽 모두 과소이나 Flash가 더 과소하다 (2.0% vs 11.0%, 실제 19.4%).

즉 **소거는 모델 공통 현상이지만 과대추정의 크기는 모델마다 다르다.** 논문의 Opus 기반 수치를 모델 일반의 수치로 읽으면 안 되며, 이 구분은 두 트랙을 나란히 놓고서야 드러난다.

## 4. 트랙별 강점과 약점

### Claude 트랙

강점
- 기제 특정: 나이 반사실 실험으로 "인구학 필드를 키로 쓰는 조회표식 결정론"을 보였고(McNemar p=0.0001), 보기 순서 뒤집기로 인공물 가능성을 배제했으며, 주입 강도 실험에서 자기 결론을 스스로 수정했다.
- 형식 이행 완벽: 재현 응답 1,158개 전부 형식 검증 통과.

약점
- 로그확률 감사 미실행 (크레딧 소진, 코드만 존재). 0%가 확률 질량의 0인지 argmax의 결과인지 구분하지 못한다.
- 모듈당 n이 작다 (반사실 15, 주입·순서 20). 다중비교를 넘지 못한 결과가 남아 있다.
- Claude Code 하네스 시스템 프롬프트가 응답 조건에 섞였다 (보고서에 명시됨).

### Gemini 트랙

강점
- 확인의 폭: 무페르소나 B 조건을 150명 전수로 실행했다 (Claude는 15명 스모크만). B에서는 고혈압·학업중단을 포함한 **전 문항이 0%**였다 — 페르소나가 대조 문항의 "예"는 만들면서 소수자 문항의 "예"는 만들지 못한다는 대비가 전수 규모로 확인된다.
- 강건성 셀: 온도 0.8·3회 반복에서 응답 일치율 96.7%, 소수자율은 사실상 불변. 거부 보기("응답하지 않음" 추가) 조건에서는 거부 13건이 발생했지만 소수자율은 그대로 0%였다.
- 주입 규모: 속성당 150명으로 Claude 모듈 3의 7.5배.

약점
- 분석 보고서가 없다. 산출물(원자료 + 검증 CSV)과 실행 코드만 있어 해석은 이 문서가 처음이다.
- 반사실·용량-반응·보기 순서 같은 기제 모듈이 없다.
- 개방형(open) 셀은 자유 응답이라 보기 번호 기반 채점이 불가능하다. 코드 기준으로는 전부 0%로 읽히지만 이는 채점 한계이며 결과로 쓸 수 없다.
- qwen25는 조건 A 55 실행 중 검증 완료가 문항당 약 5건인 부분 결과로, 신호 이상의 무게를 둘 수 없다.

## 5. 공유하는 한계

- 문항이 논문 원문이 아니다 (보충표 2 미공개, 원문 확인 2문항). 따라서 양쪽 모두 논문 수치의 문자 그대로의 재현이 아니라, 같은 재구성 문항 위에서의 **현상의 재현**이다. 역으로, 문항·표본이 같기 때문에 두 트랙 사이의 비교 자체는 엄밀하다.
- 두 트랙 모두 단일 온도 중심 설계다 (Gemini의 T=0.8 셀이 부분적으로 보완).
- B 조건은 혼인 상태가 없어 배우자 폭행 문항을 전원에게 묻는다. Gemini B의 해당 문항 0% (0/150)는 이 설계 아래 읽어야 한다.

## 6. 종합

Claude 트랙이 "왜 그런지"(기제)를 밝혔고, Gemini 트랙이 "모델을 바꿔도 그런지"(일반성)를 확인했다. 경쟁 결과가 아니라 상호 보완이다. `muse-exp/`의 로그확률 감사(Qwen2.5-1.5B)는 소수자 선택지의 확률 질량 자체가 0에 가깝다는 증거를 더해, Claude 트랙이 비워 둔 로그확률 칸을 작은 모델에서나마 채운다.

논문 원문(보충표 2)이 공개되면 두 트랙 모두 같은 코드로 원문 문항 재실행이 가능하고, 그 시점에 이 비교를 다시 수행하는 것이 다음 단계다.
