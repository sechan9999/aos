# 모듈 4. 보기 순서 민감도

실행일 2026-10-21 · 응답자 Opus subagent (페르소나마다 새 대화, 조건은 파일 번호로 가림)

## 1. 설계

□ 질문
  ○ 논문의 핵심 결과(장애 등록 0%, 자살 생각 0%)가 문항 설계에서 나온 것인지, 모델이 답을 고르는 방식에서 나온 것인지 가름
  ○ 보기 번호만 뒤집고 뜻은 그대로 두었을 때 같은 사람의 답이 바뀌는지 봄

□ 조건
  ○ 페르소나 20명 고정(모듈 3·3b와 같은 표본, random_state=7)
  ○ 주입 조건 2종 — C0b 주입 없음, C1b 장애 라벨 명시
  ○ 보기 순서 2종 — orig(1=예 / 2=아니오), rev(1=아니오 / 2=예)
  ○ 사람 안에서 짝지은 쌍 40개(C0b 20 + C1b 20), 문항 9개
  ○ self_health는 orig가 1=매우 좋음 … 5=매우 나쁨, rev가 그 역순. 뜻 기준으로 되돌려 비교

□ 제외
  ○ unmet_reason 1문항. 문두에 "해당 없으면 5"가 박혀 있는데 보기만 뒤집혀 rev에서 문두 번호와 라벨이 어긋남
  ○ 설계 결함이며, 응답자 2명이 독립적으로 같은 문제를 보고함. 번호를 문두에 넣은 문항은 이 문항뿐이라 나머지는 영향 없음

## 2. 결과

□ 전체 일치율 90.0% (320개 쌍-문항 중 32개 불일치)
  ○ C0b 88.1%, C1b 91.9%

□ 논문의 두 핵심 문항은 순서에 전혀 흔들리지 않음
  ○ disab_reg — C0b 0/20 → 0/20, C1b 20/20 → 20/20, 일치율 100%
  ○ suic_idea — 두 조건 모두 0/20 → 0/20, 일치율 100%
  ○ 장애·자살 생각의 0% 결과는 보기 순서가 만든 인공물이 아님

□ 흔들린 문항은 discrim 하나
  ○ C0b에서 "차별 경험 있음" 12/20 → 5/20, 불일치 9명, McNemar p=0.039
  ○ 8문항을 함께 본 Bonferroni 기준값 0.00625보다 크므로 다중비교를 감안하면 확정적이지 않음
  ○ C1b에서는 17/20 → 16/20으로 거의 움직이지 않음

□ self_health도 주입이 없을 때만 움직임
  ○ C0b 평균 2.95 → 2.60, 20명 중 7명 변동, Wilcoxon p=0.008 (1=매우 좋음 … 5=매우 나쁨)
  ○ C1b 평균 3.05 → 3.05, 20명 중 2명 변동, p=1.000

| 문항 | C0b 일치율 | C1b 일치율 |
|---|---|---|
| disab_reg | 100% | 100% |
| suic_idea | 100% | 100% |
| social_support | 100% | 95% |
| depress_2wk | 80% | 100% |
| activity_limit | 95% | 85% |
| disab_self | 100% | 85% |
| unmet_care | 75% | 85% |
| discrim | 55% | 85% |

## 3. 해석

□ 논문 결과의 방어
  ○ 소수자 정체성 문항의 극단적 0%는 보기 배치에 따라 생긴 것이 아님
  ○ 이 점에서 논문의 핵심 주장은 순서 민감도 검증을 통과함

□ 새로 드러난 비대칭
  ○ 속성을 주입하지 않은 C0b가 주입한 C1b보다 순서에 더 흔들림 (88.1% 대 91.9%)
  ○ 흔들린 두 지표 discrim과 self_health 모두 C0b에서만 움직이고 C1b에서는 멈춤
  ○ 주입한 라벨이 닻 노릇을 해 응답을 고정시키는 것으로 읽힘

□ 해석의 한계
  ○ 근거는 쌍 40개로 약함. discrim의 p=0.039는 단일 검정 기준에서만 유의하고 다중비교를 넘지 못함
  ○ "라벨이 닻이 된다"는 설명은 지금 자료와 맞을 뿐 검증되지 않음. 대안 해석으로, 주입이 없을 때 모델이 기본값에 가까운 답을 내면서 작은 자극에도 밀리는 것일 수 있음
  ○ C2b(서술형 암시)는 orig만 돌려서 순서 분석에 들어가지 않음
