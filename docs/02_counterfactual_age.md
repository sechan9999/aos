# 나이 반사실 실험 — 고혈압·학업중단 응답이 나이만으로 뒤집히는가 (2026-10-19)

## 설계
- 대상: 100명 중 60세 이상 15명, 40세 미만 15명 (무작위 추출)
- 조작: `age` 필드만 교체 (고령→30세, 청년→75세). 나머지 25개 필드는 그대로
- 조건 4개, 같은 사람 안에서 쌍 비교
  - A_orig: 전체 페르소나, 원래 나이 (기존 100명 실험 결과 재사용)
  - F_flip: 전체 페르소나, 나이만 교체
  - D_orig: 인구학 12필드만 (서술형 13필드 제거), 원래 나이
  - D_flip: 12필드만 + 나이 교체
- 모델: 현재 세대 Opus, subagent 1인 1대화, 기본 온도. 파일 번호 무작위로 섞어 조건 은폐
- 설계상 한계: 서술형 필드에 나이 단서가 거의 모든 페르소나에 들어 있음 (<40세 29/32, 60+ 37/40). D 조건이 이 교란을 제거한 설계

## 핵심

□ **고혈압은 나이가 완전히 결정한다**
- 서술형 필드를 제거하면 나이 숫자 하나로 100% 뒤집힌다. 15명 전원이 양방향으로 바뀜
- 전체 페르소나에서는 40~53%만 바뀐다. 서술형 필드가 나이에 저항하는 단서를 제공
- 저항 사례: 88세→30세인데도 "나이가 있으니 혈압약을 먹은 지 오래요" (원래 서술에 혈압약 언급)

□ **학업중단은 나이와 무관하다**
- 나이를 바꿔도 0건 변화. 대신 `education_level`이 완전히 결정
- D_flip 기준: 초등학교 6/6 전원 예, 중학교 4/4 전원 예, 고등학교 이상 20명 전원 아니오
- 즉 "저학력 = 생계 곤란으로 중퇴"라는 결정론적 규칙

□ **해석**
- 모델은 고통을 무작위로 지우지 않는다. 인구학 필드 하나를 조회표 키로 써서 결정론적으로 배분
- 서술형 필드는 이 결정론을 절반쯤 완화하는 역할. 논문이 서술형까지 넣은 설계는 오히려 편향을 줄인 쪽
- 소수자 0% 현상과 과대추정 현상이 같은 기제에서 나온다: 인구학 필드에 없는 속성은 0, 있는 속성은 전형값으로 고정

## 한계
- n=15/집단. 현재 세대 Opus, Claude Code 하네스 시스템 프롬프트 포함, 기본 온도 1회 샘플
- 문항은 논문 원문이 아닌 초안 (학업중단·고혈압 모두 초안)
- 나이 교체 시 서술형 내용과 모순 발생 (22세 서술에 75세 표기). 이 모순 자체가 D 조건을 필요하게 만든 이유
