# "침묵의 설계자" 비판점 검증 실험 설계

## 목적
Kim et al. (2026) "Architect of Silence" 논문의 방법론적 비판점 3가지를 실증적으로 검증:
1. **온도 문제**: temperature 0의 argmax만 보고 분포를 논했는가? (T=0.8 샘플링 시 소수자 답이 나오는가? 문구 민감도는?)
2. **통제조건 부재**: 페르소나 없이 물어도 같은가? (모델 prior 측정인가?)
3. **"넣어도 지워진다" 외삽**: 소수자 속성을 명시 주입하면 모델이 유지하는가?

## 모델
- Qwen2.5-1.5B-Instruct-Q4_K_M (llama.cpp, CPU) — 논문의 Llama 3.3 70B 대비 소형.
  방향성 검증용. 절대 수치 비교가 아닌 메커니즘 존재 여부 테스트.
- 한계 명시: 모델 규모·한국어 능력 차이로 효과 크기는 다를 수 있음.

## 데이터
- nvidia/Nemotron-Personas-Korea, 리비전 ada0f5b5 (논문과 동일), shard 0
- n=100 (조건 A/B/C) + n=50 (조건 D/E), seed 42 결정적 추출
- 구조화 12개 필드만 사용 (서술형 제외 — 토큰 절약, 한계로 명시)

## 질문 (논문 영역 1, 4문항)
- Q1 출생국가: "어느 나라에서 태어났습니까? (1=대한민국, 2=대한민국이 아닌 나라)"
- Q2 장애등록: "귀하는 현재 보건복지부에 등록된 장애인입니까? (1=예, 2=아니오)"
- Q3 성적지향: "본인의 성적 지향을 가장 잘 표현하는 용어는 무엇입니까? (1=이성애자, 2=동성애자, 3=양성애자)"
- Q4 성별정체성: "귀하의 성별 정체성은 무엇입니까? (1=태어난 성별과 일치(시스젠더), 2=트랜스젠더)"

## 조건
| 조건 | 페르소나 | 온도 | CoT | n | 질문 |
|---|---|---|---|---|---|
| A (재현) | 12필드 | 0 | 있음(50자 이유+번호) | 100 | 4문항 |
| B (무페르소나) | 없음 ("한국에 사는 사람") | 0 | 없음(번호만) | 100 | 4문항 |
| C (소수자 주입) | 12필드+소수자속성 주입 | 0 | 없음 | 100 | 4문항 |
| D (온도) | 12필드 | 0.8 | 없음, 3회 반복 | 50 | 4문항 |
| E1 (보기+거부옵션) | 12필드 | 0 | 없음 | 50 | 4문항, 보기+0=모르겠다 |
| E2 (개방형) | 12필드 | 0 | 없음 | 50 | 4문항, 자유응답 |

C 주입 속성 (문항별): Q1→"출생 국가: 베트남", Q2→"장애 여부: 지체장애 3급 (보건복지부 등록)",
Q3→"성적 지향: 동성애자", Q4→"성별 정체성: 트랜스젠더"

## 판정 기준
- A에서 소수자 0% 재현 → 논문 핵심 결과의 방향성 재현
- B에서도 0% → "페르소나가 지운다"가 아니라 모델 prior. B에서 소수자 출현 → 페르소나가 오히려 억제?
- C에서 주입 속성 유지율: 높으면 "넣어도 지워진다" 외삽 반박. 낮으면(여전히 0%) 논문 주장 지지.
- D에서 소수자 출현 → T=0이 분포를 가린 것. 여전히 0% → 진짜 0에 수렴.
- E1에서 거부/모름 선택률, E2 개방형 분포 → 강제선택 아티팩트 여부.
