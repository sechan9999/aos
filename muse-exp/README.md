# muse-exp — 로그확률 감사와 120B 샘플링 재현 (Muse 에이전트 트랙)

이 폴더는 저장소 루트의 Claude 트랙(`src/`, `docs/`)과 별개로, Muse 에이전트가 2026-10-19부터 독립 실행한 검증 실험입니다. 같은 논문(「침묵의 설계자」)을 다른 각도에서 검증합니다.

## 무엇이 다른가

| | 루트 Claude 트랙 | 이 트랙 (muse-exp) |
|---|---|---|
| 모델 | Claude Opus (하네스) | Qwen2.5-1.5B (로컬, 로그확률) + gpt-oss-120b (Groq) |
| 측정 | 생성 답변 1회 샘플링 | **로그확률 분포 자체**를 측정 (1.5B) / 반복 샘플링+거부 분류 (120B) |
| 페르소나 표본 | 논문 공개 1k에서 150명 | NPK 샤드0 앞 20,000행에서 reservoir, seed 42, 150명 — **논문 응답과 uuid 짝짓기 불가** |
| 문항 | 재구성 12문항 | 발표자료 기반 재구성 4문항 (Q1 출생국가·Q2 장애등록·Q3 성적지향·Q4 성별정체성) |

## 구성

- `DESIGN.md` — 설계 A (샘플링 기반 분포 추정)
- `DESIGN-B.md` — 설계 B (로그확률 감사 우선) — 실제 실행한 설계
- `REPORT.md` — 1.5B 실험 최종 보고서 (완료)
- `analyze.py` — 결과 집계
- `src/` — 실행 코드 (`run_logprob.py`, `run_inject.py`, `run_wording.py`, `run_groq.py`, `run_exp.py`, `validate.py`)
- `out/` — 응답 원자료. `results_groq.jsonl`은 **진행 중 스냅샷** (2026-10-22 기준 1,646/3,300)
- `data/sample_150_muse.uuids.txt` — 이 트랙의 표본 uuid 목록 (원자료는 재배포하지 않음)

## 핵심 결과 (1.5B, REPORT.md 요약)

논문에 대한 세 가지 비판을 검정했습니다.

1. **"T=0 탐욕 디코딩의 착시" → 기각.** Q1·Q2·Q4의 소수자 확률 자체가 0.1–1.4%로, 분포에 없습니다.
2. **"페르소나 내용이 아니라 모델 prior 문제" → 지지.** 셔플 페르소나 ≈ 진짜 페르소나 ≈ 무페르소나. 지우기는 페르소나가 아니라 모델이 합니다.
3. **"스키마에 넣어도 지워질 것" → 기각 (지지 방향).** 명시 주입 시 Q4 1.4%→99.8%, Q2 0.2%→75.1%. **처방: 스키마에 명시 필드를 넣으면 됩니다.** 단 암시적 힌트는 거의 작동하지 않습니다.

예외: 1.5B 모델은 Q3(성적지향)에서 오히려 "동성애자"를 97% 골랐습니다. 지우기는 보편 법칙이 아니라 모델 의존 현상입니다.

## 120B 실행 (진행 중)

Groq 무료 티어로 `openai/gpt-oss-120b`에서 같은 설계를 샘플링 방식으로 재현 중입니다 (로그확률 미지원이라 반복 샘플링). 중간 결과 (M1 완료, n=100/조건):

- 소수자 답변 0%는 전 조건·전 문항 재현
- 단, 메커니즘이 다릅니다: Llama의 "지우기"가 아니라 **답변 거부** — Q3 페르소나 조건 거부 87%, Q4 무페르소나 조건 거부 100%
- 셔플 ≈ 페르소나 → 비판 2가 120B에서도 확인

완료 후 이 폴더에 최종 보고서를 추가합니다.

## 실행 방법

```bash
# 1.5B 로컬 (llama-cpp-python, GGUF 모델 별도 다운로드)
python src/run_logprob.py    # 로그확률 감사
python src/run_inject.py     # 주입 용량-반응
python src/run_wording.py    # 문구·보기순서

# 120B (Groq API 키 필요 — 코드에 키를 넣지 않고 보안 저장소에서 주입)
python src/run_groq.py       # 중단 후 재실행하면 이어서 진행 (results_groq.jsonl 기준)
```

## 제약

- 1.5B 결과는 논문의 70B와 규모가 달라 방향성·메커니즘 검정으로만 읽어야 합니다.
- 120B는 논문의 Llama와 패밀리가 다릅니다. "같은 결론, 다른 메커니즘" 자체가 이 트랙의 발견입니다.
- 문항은 발표자료 기반 재구성입니다. 논문 원문 문항이 아닙니다.
